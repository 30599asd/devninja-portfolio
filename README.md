# Portfolio 

Minimalist developer portfolio using Next.js 14, React, TailwindCSS, Framer motion

# Features

- Built using Next.js 14, React, Typescript, Shadcn/UI, TailwindCSS, Framer Motion, Eldora UI
- Responsive for different devices
- Optimized for Next.js and Vercel

# Getting Started Locally

1. Clone this repository to your local machine:

   ```bash
   git clone https://github.com/super-devninja/portfolio-template
   ```

2. Move to the cloned directory

   ```bash
   cd portfolio-template
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the local Server:

   ```bash
   npm run dev
   ```

5. Open the [Sections](https://github.com/super-devninja/portfolio-template/tree/main/app/sections) folder and make changes
